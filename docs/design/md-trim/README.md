## 왜

## jin 이 정한 구조 (3단)
1. **매 세션 읽는 핵심** — 돈 · 역할 · 락 + (내가 제안해 넣기로 한) 배포·금지 명령 · 진행상태 10단계 · 「떠난 차」 판정 · 누르면 안 되는 것 · 세션 간 통신 규약.
   줄이지 않고 **코드와 대조해 다시 쓴다**(원본을 줄이는 게 아니다). jin «돈 관련은 절대 틀어지고 까먹으면 안 된다».
2. **색인 한 줄(쓸 때만 불러옴)** — 공용 부품·서류 양식·알림톡 등록·가이드 촬영 등. Claude Code 스킬로 옮긴다(설명 한 줄만 실리고 본문은 부를 때 읽힌다).
3. **보관** — 경위·날짜·그때의 실측. `docs/archive/` 로.

핵심 목록 전문(항목별) = 메모리 `project_md_context_trim` 「매 세션 읽을 핵심 목록」.
