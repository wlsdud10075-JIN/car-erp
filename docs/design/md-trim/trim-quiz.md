# 줄인 문서 읽기 시험 — 질문 50개

각 질문에 「줄인 판 파일에 적힌 내용만으로」 답한다. 답마다 근거 줄 번호를 붙인다. 파일에 없으면 「없음」.

## A. 배포·git (주말 배포 때 필요)
1. master 에 push 하면 무슨 일이 일어나나? 몇 개 회사가 영향을 받나?
2. 배포 전에 매번 확인해야 하는 항목은?
3. push 뒤 배포가 성공했는지 무엇으로 확인하나(잡 이름까지)?
4. master 에 「tests」 워크플로 런이 안 보인다. 테스트가 안 돈 것인가?
5. dev 에서 master 로 코드를 옮기는 명령 순서는? cherry-pick 과 push 를 한 줄에 묶어도 되나?
6. .md 파일이나 scripts/notion-* 이 섞인 커밋은 어떻게 다루나?
7. 테스트 게이트에서 실패하면 master 를 revert 해야 하나?
8. 커밋 메시지를 Bash 에서 쓸 때 주의할 점은?
9. feature 브랜치나 PR 을 만들어야 하나?

## B. 금지·안전
10. php artisan key:generate 를 실행해도 되나? 왜?
11. pint 를 .blade.php 에 돌려도 되나?
12. 로컬에서 php artisan serve 로 서버를 띄워도 되나?
13. migrate:fresh 를 로컬에서 써도 되나?
14. `verified` 미들웨어가 있으면 접근이 보호되나?
15. users.role 기본값 '전체' 를 유효한 값으로 정리해도 되나?

## C. 코딩 규칙 (공용 부품 작업 때 필요)

17. 새 Volt 화면을 만들 때 반드시 붙여야 하는 속성은?
18. 새 Tailwind 클래스를 썼는데 화면에 안 먹는다. 무엇을 확인하나?
19. 사용자가 「화면이 느리다」고 한다. 먼저 무엇을 확인하나?
20. 판매채널(sales_channel)에 새 값을 추가해 분기를 만들어도 되나?
21. 차량 진행상태는 DB 컬럼인가? 목록 필터는 무엇으로 거나?

## D. 가이드·문서

## E. 협업·명칭
