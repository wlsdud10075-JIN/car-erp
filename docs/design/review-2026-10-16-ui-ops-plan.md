## 영상 「3초 테스트」(2026-10-16, jin 전달) — 디자인 다듬기 원칙

- 출처 = 두아르테(HBR) 글랜스 테스트: 처음 보는 사람이 **3초 안에 핵심 메시지 하나**를 읽어야 한다. 고속도로 광고판 비유.
- 방법 = **더하지 말고 뺀다**(Refactoring UI 「덜 강조해서 강조하라」). 핵심 하나를 살리고 나머지는 그걸 **뒷받침**하도록 무게를 낮춘다. 🚫 전부 지우라는 뜻이 아니다 — **우선순위**를 바꾸는 것.
- 지시 수준 = **무엇(WHAT)은 우리가, 어떻게(HOW)는 AI가**. 글꼴·여백을 하나하나 지정하면 더 좋은 배치를 막고, 「더 괜찮게」 같은 막연한 말은 평균으로 돌아간다.
