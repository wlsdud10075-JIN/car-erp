## 1. 관리자 대시보드 (`/admin/dashboard`)

**지금(인벤토리)**: 헤더(기준일·기간·[조회]·위젯 설정) → 빠른 선택 → 탭 4(영업/수출통관/재무/채권) → 자금 현황(카드 3·추이 차트) → KPI 5 → 진행 단계 스트립 → 통관 → 정산(차트·표) → 담당자 차트 2 → 월별 차트 2 → 채권 블록(탭) → 각주. **KPI 24장·차트 6·표 3**. 회사 순이익은 「재무」 탭 안쪽, 미수는 KPI 와 채권 탭에 **두 번**.

1. **일·사람**: 대표가 하루 한두 번, PC 또는 폰. 3초에 읽어야 할 것 = **이번 달 회사이익**과 **받을 돈**(jin «1,2번이지»). 결과 화면이지 할 일 화면이 아니다.
2. **결과·근거**: 첫 화면(스크롤 전)에 숫자 **둘**만 크게 — ① 회사 순이익(급여 차감 후, 이번 달) + 한 줄 근거(총마진 − 실지급 − 발송비 − 공통 인건비) ② 총 미수금(₩) + 「위험·심각 n대」. 둘 다 누르면 근거 화면(정산관리·채권관리)으로.
3. **방향**: 「리드 2칸 → 근거 띠 → 상세」 3층. 근거 띠 = 자금 현황(현금·총자금·번 돈)과 이달 KPI(판매·회수·대수)를 **한 줄 크기**로. 상세(차트·표·통관·정산)는 탭 그대로 아래. 자금 현황은 리드에서 빼고 근거 띠로 **낮춘다**(기밀이라 `canViewCapital` 조건은 유지).
4. **범위·경계**: 탭 4개·위젯 토글·날짜 필터·[조회] 유지. 미수 KPI 중복은 리드로 **합친다**(채권 탭엔 분류·TOP10 만 남김). 차트는 축소하지 않되 리드 아래로. 결재 승인은 이 화면에 없다 — 안 만든다.
5. **상태·범위**: 회사이익은 음수 가능(빨강). 미수 0 이면 「받을 돈 없음」 빈 상태. 자금 추이는 데이터 2건 미만이면 안 그림(현행). 억 단위 표기 유지. 3사 규모 = 미수 수십~수백 대.
6. **상호작용·배치**: 리드 2칸은 PC 2열·폰 1열 세로. 근거 띠는 폰에서 가로 스크롤 없이 2열 접힘. 상세 차트는 폰에서 1열. 폴링 30초 유지.
7. **제약·미결**: 숫자 출처 불변(`companyProfit`·`receivableKpis`·`capitalStatus`). **미결**: 회사이익과 미수 중 왼쪽(먼저) 둘 것 — 제안은 회사이익 왼쪽(월 결산 알림톡과 같은 순서). 기간 필터가 리드에도 걸리는지 — 제안: 리드는 「이번 달」 고정 표시, 필터는 상세에만(채권은 원래 기간 무관).

## 2. 업무 대시보드 (`/erp/dashboard`)

**지금(인벤토리)**: 헤더(담당자별|역할별 토글·역할 탭·담당자 드롭다운) → 단계 스트립 → KPI 4~6 → 실시간 환율 5칸 → 통장 마감잔액 입력(재무·업무관리자·대표) → **처리 필요 항목**(역할별 6~11행, count>0 만) → 진행중 차량 표. 할 일이 **네 번째 블록**이라 첫 화면에 안 보일 수 있다. KPI 와 할 일이 같은 것을 두 번 센다(재무: 매입 미지급 총액 KPI ↔ 매입 미지급 할 일).

1. **일·사람**: 관리·업무관리자·수출통관이 PC 에서 종일 켜 두고 **놓친 일**을 잡는다(jin «놓친 일을 한눈에 볼 수 있게 행동양식으로»). 재무는 같은 화면에서 잔액 입력. 영업은 폰에서 본인 것.
2. **결과·근거**: 3초에 읽을 것 = **「지금 처리할 일 N건, 그중 급한 것 n」**. 각 행이 곧 버튼(차량관리 필터로 이동) — 현행 유지.
3. **방향**: 「할 일이 첫 블록」. 처리 필요 항목을 맨 위로 올리고 **urgent 행을 먼저**, 행마다 건수 + (돈이면) 금액을 같은 줄에. KPI 카드는 **할 일 행 안으로 흡수**(「매입 미지급 12건 · ₩3.2억」) — 카드 그리드는 없앤다. 단계 스트립·환율·진행중 차량은 아래로 낮춤. 빈 상태(0건)는 현행 초록 체크 문구 유지.
4. **범위·경계**: 역할별 할 일 목록·링크·권한 조건 불변. 담당자별|역할별 토글과 드롭다운은 헤더 그대로. **통장잔액 입력 카드**는 재무·업무관리자에게만 보이는데, 할 일 바로 아래에 **한 줄 띠**(「오늘 잔액 미입력」 뱃지 + [입력] 펼침)로 낮춘다(미결 → 제안). 환율 5칸은 한 줄 텍스트로.
5. **상태·범위**: 할 일 0~11행, 건수 0~수백. 담당자 미연결 안내(영업)는 그대로. 통장 계좌 0개(3칸 모드)·n개(드롭다운 모드) 둘 다.
6. **상호작용·배치**: PC 는 할 일(좌, 넓게) + 단계 스트립·환율(우, 좁게) 2열도 가능하나 제안은 **1열 세로**(종일 켜 두는 화면은 스캔 순서가 일정해야). 폰은 1열, desc 숨김 유지, 진행중 차량 카드 유지.
7. **제약·미결**: `actions()`·`kpis()` 출처 불변(화면이 합치기만). **미결**: 담당자 선택기 위치(헤더 유지 제안), 통장잔액 띠의 위치(할 일 아래 제안), KPI 카드를 완전히 없앨지 행에 흡수할지(흡수 제안).

## 3. 채권관리 (`/erp/receivables`)

**지금(인벤토리)**: 헤더(페이지당·권한 문구) → 분류 탭 6 → 합계식 안내 → 조건부 띠 2 → 통화 pill → KPI 5 → 필터 바 8종(검색·기간·담당자·바이어·진행상태·위험도·취소·미납률) → 표 **14열** → 페이지네이션 → 회수 이력 슬라이드 패널(방법 6종). 행에 버튼 없음(행 클릭=패널). 주의·위험 뱃지 색이 같다. 폰 카드엔 판매합계·진행상태·BL·채권담당 없음.

1. **일·사람**: 관리·업무관리자·재무. 목적 = **전체 미수 규모를 보고**(3) **특정 차량·바이어를 찾는다**(4), 찾은 뒤 회수 기록.
2. **결과·근거**: 3초에 읽을 것 = **총 미수금(₩) + 선적후/선적전 몫 + 위험·심각 n대**. 그 옆에 **검색창**이 리드와 같은 무게(찾기가 목적).
3. **방향**: 「리드 숫자 3 + 검색 → 탭 → 표」. KPI 5장은 리드 1줄로 **합친다**(총 매출·총 입금은 리드 아래 작은 글씨). 필터 8종 중 **위험도·담당자**만 노출, 나머지(기간·바이어·진행상태·취소·미납률)는 「필터 더보기」 접힘. 표는 **9열**로: 차량(번호 + 아래 줄에 브랜드·VIN 끝 6) · 담당 · 바이어 · 판매합계 · 미납금(+% 같은 칸) · 경과일 · 위험도 · BL(뱃지) · 채권담당. 번호 열은 뺀다(행 번호는 정렬에 의미 없음). 주의/위험 색을 **갈라** 놓는다(주의 amber·위험 orange).
4. **범위·경계**: 탭 6·합계식·통화 pill·조건부 띠·회수 패널(방법 6종·과입금 전환·담당 지정) **불변**. 행 클릭 = 패널 유지. 알림톡·독촉 버튼은 안 만든다(현행에도 없음, 알림톡은 스케줄). 표 열은 「표시 컬럼 선택」으로 되살릴 수 있게(차량관리와 같은 방식)는 **후보**지 이번 범위 아님.
5. **상태·범위**: 미수 0 → 빈 상태. 행 수십~수백(페이지당 10~100). 통화 섞임(₩/$/€). 매입취소·임포트 정리분 띠는 있을 때만.
6. **상호작용·배치**: 리드 숫자 3 + 검색은 PC 1줄, 폰 2줄. 표는 PC, 폰은 카드(카드에 판매합계·BL 추가). 행 배경 게이지는 유지(범례 없음 — jin 결정).
7. **제약·미결**: KPI·등급 출처 불변(`receivable_risk`·`sale_unpaid_amount`). **미결**: 접힌 필터에 「기간」을 넣을지 노출할지(제안: 접힘 — 미수는 기간으로 안 자르는 원칙과 맞음), 번호 열 제거 가부.
