  2. 「지금 할 일」에 들어가는 조건은 경과시간이 아니라 이유다 — 다른 사람·돈이 막힘, 시간 민감, 오늘 마감, 놓치면 손실. 이유를 행에 적는다.
  3. 「놓쳤을 가능성」 = 마감 지남 · 「넵」만 하고 처리 확인 없음 · 재확인 시점 지남 · ERP 에 연관 기록 없음. 확정이 아니라 가능성이므로 확인을 청한다.
  4. 미루기는 반드시 다시 나타날 조건을 정한다(시각 · 상대 답 · ERP 상태). 그냥 숨기는 「나중에」는 없다.

  6. 행 = 동사형 제목 · 누가↔누구 · 시각·방 · 마감/재확인 시점 · 지금 보여주는 이유 · 핵심값(차량번호·금액) · [완료][미루기][⋯]. 행을 누르면 원문·앞뒤 대화·「분류 수정 / 내 일이 아님 / ERP 확인」.
