테마가 퍼지는 순서

누구나① 내 테마 만들기색 6개를 고르고 저장. 내 화면에만 적용됩니다. 마음에 들면 이름을 붙여 「추천 올리기」.
업무관리자 이상② 프리셋으로 등록「추천 받은 테마」에서 미리보기 → 등록 또는 돌려보내기. 자기 테마는 바로 등록할 수 있습니다.
누구나③ 프리셋 적용프리셋 목록에서 [적용]. 적용한 뒤 내 취향대로 더 고쳐도 됩니다(내 복사본).
시스템관리자만④ 회사 기본 지정프리셋 하나를 회사 기본으로. 자기 테마를 저장하지 않은 사람에게만 적용됩니다.
적용 순서: 내 테마 → 없으면 회사 기본 → 없으면 지금의 보라색. 프리셋은 회사별로 따로입니다.
