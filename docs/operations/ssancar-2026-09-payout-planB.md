| | 안 A (차량별 CS) | 안 B (실지급액) |
|---|---|---|
| **맞는 것** | 차량별 마진·정산액이 ERP 공식과 이어진다. 561대 전부에 근거가 있다 | 통장 기록과 1원도 안 틀린다 |
| **잃는 것** | 통장과 4,534만원 차이. 「왜 ERP 가 적지?」가 남는다 | **차량에 못 나눈다** — 보너스·지급보류 해제·예치금은 특정 차의 마진이 아니다 |
| **ERP 어디에 담기나** | `Settlement.actual_payout` (안 A 스크립트 완성) | 정산은 CS 로 두고, 나머지는 **`SettlementPayoutBatch` 수동 조정**(§8 #28-2)·`carryover_in_krw` |

### 🔑 사실은 **섞는 게 정답일 수 있다** — ERP 에 이미 자리가 다 있다

```
차량별 정산(CS)            → Settlement.actual_payout      ← 안 A 스크립트 그대로
전월 비용 추가정산 159,171 → Settlement.carryover_in_krw   ← ERP 의 이월 개념과 정확히 같다
보너스·보류해제·예치금     → 월배치 수동 조정              ← 차량과 무관한 것은 여기 자리다

                            합계가 통장(107,643,235)과 맞는다
```
